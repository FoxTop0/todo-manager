# ✅ Todo List Manager

Консольное приложение для управления списком дел с модульной архитектурой.

## 🎯 Функционал

- ➕ Добавление задач
- 📋 Просмотр всех задач
- ✅ Отметка задач как выполненных
- ❌ Удаление задач
- 🔍 Поиск по ключевым словам
- 📊 Статистика выполнения
- 💾 Автоматическое сохранение в JSON
- 📁 Бэкапы данных

## 🏗️ Модульная структура

| Файл | Назначение | Разработчик |
|------|------------|--------------|
| `main.py` | Пользовательский интерфейс, меню | Dev 1 |
| `storage.py` | Работа с JSON файлами, бэкапы | Dev 2 |
| `task_manager.py` | Логика управления задачами | Dev 3 |
| `validator.py` | Валидация входных данных | Dev 4 |
| `logger.py` | Логирование операций | Dev 5 |
